# ملتقى الإبداع التقني

موقع تعريفي لفعالية، مبني بـ React، يعرض التاريخ والمكان وبرنامج اليوم، ويتيح التسجيل عبر نموذج مع التحقق من البيانات.

## المزايا

- عدّاد تنازلي حتى موعد الفعالية
- التاريخ والوقت والمكان في الواجهة الرئيسية، وقسم تعريفي بالفعالية
- برنامج اليوم في جدول مرتب
- نموذج تسجيل (الاسم، البريد الإلكتروني، الجوال) مع رسائل خطأ واضحة
- تصميم عربي من اليمين لليسار، ومتجاوب مع الجوال

## التقنيات

React 18 · Vite · CSS · خط Almarai · ألوان Pantone 621–627

## هيكل المشروع

```
event-site/
├── index.html        صفحة HTML الوحيدة التي يحمّلها المتصفح
├── package.json      المكتبات وأوامر التشغيل
├── vite.config.js    إعدادات أداة البناء
├── .gitignore        ملفات لا تُرفع إلى GitHub
├── README.md         توثيق المشروع
└── src/
    ├── main.jsx      نقطة بداية React
    ├── App.jsx       محتوى الموقع ومنطقه
    └── App.css       الألوان والخطوط والتنسيق
```

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (غالبًا `http://localhost:5173`).

## تعديل بيانات الفعالية

افتح `src/App.jsx` وعدّل الكائن `EVENT` (الاسم، التاريخ، المكان، عدد المقاعد) والمصفوفة `PROGRAM` (برنامج اليوم) في أعلى الملف.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع المشروع:
   ```bash
   git init
   git add .
   git commit -m "إضافة موقع الفعالية"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
2. انشر الموقع:
   ```bash
   npm run deploy
   ```
3. من إعدادات المستودع (Settings ← Pages) اختر الفرع `gh-pages`.
4. سيكون الرابط: `https://USERNAME.github.io/REPO/`

## أوامر مفيدة

| الأمر | وظيفته |
|---|---|
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` | بناء النسخة النهائية في مجلد `dist` |
| `npm run preview` | معاينة النسخة النهائية محليًا |
| `npm run deploy` | بناء الموقع ونشره على GitHub Pages |
